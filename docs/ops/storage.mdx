# 存储与中间件

> TODO：补充容量估算、索引维护、Qdrant Collection 命名约定与备份脚本占位。

## PostgreSQL

- 数据：用户、角色、部门、文档元数据、文件夹、AI 会话与消息。
- 维护：常规 `VACUUM`、慢查询巡检、连接池监控。

## MinIO

- 数据：原始文档、附件、头像。
- 维护：桶策略、访问日志、版本控制（按需开启）。

## Redis / Asynq

- 数据：异步任务队列、任务状态。
- 维护：内存上限、慢命令、持久化策略（按需开启 AOF）。

## Qdrant

- 数据：文档切片向量与 payload。
- 维护：Collection 列表、向量维度、payload 索引。
- Collection 与文档库/知识库的映射约定（命名与隔离）。
