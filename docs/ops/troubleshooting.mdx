# 排错

> TODO：补充日志位置、典型错误消息与诊断命令。

## 启动失败

- 后端启动报错连接 Postgres/Redis/MinIO/Qdrant：检查 `.env` 与基础设施状态。
- 缺任务 Worker：确认 `infrastructure/queue` 已启动并注册任务 handler。

## 文档解析失败

- 任务队列显示失败：查看任务 payload 中的错误信息。
- 重新上传或手动重试；如反复失败，确认文档类型是否在解析器覆盖范围内。

## 检索无结果

- Embedding 模型未配置或失败 → 模型配置页确认凭据与可达性。
- Qdrant Collection 不存在或维度不匹配 → 重新触发文档处理。
- 权限过滤过严 → 用管理员账号或扩大文件夹授权验证。

## 聊天流中断

- SSE 提前断开：检查反向代理超时与缓冲设置。
- 持续报 `rate limit`：检查模型 Provider 配额与并发设置。

## 性能问题

- 大文档解析慢：调整切片参数或拆分文档。
- 向量召回慢：检查 Qdrant Collection payload 索引与向量数量级。
