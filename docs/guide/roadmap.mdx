# 路线图

本页追踪 SAG Wiki 的近期演进方向，便于文档、配置和功能之间的同步。

## 进行中

- 把三仓（`sag-wiki-app` / `sag-wiki-server` / `sag-wiki-docs`）的 README、AGENTS.md、文档站同步到同一份边界约定。
- 用户手册、开发者手册、运维手册三类文档的骨架搭建（当前阶段）。

## 计划中

- 用户手册：知识库、问答、模型配置、任务队列、系统管理各自的完整操作流与截图位。
- 开发者手册：前后端分层、RAG 链路、数据模型、API 约定、测试组织。
- 运维手册：环境变量清单、生产部署建议、各存储数据备份策略、常见排错。

## 暂未覆盖

- 多租户隔离：当前权限模型按目录树 + 用户/角色/部门划分，不提供跨租户隔离。
- 端到端集成测试：后端已有 Go 单元测试，前端 Vitest 覆盖页面与请求层，尚未接入 Playwright 浏览器测试。
- 离线模型推理：当前依赖外部 OpenAI-compatible API，未集成本地推理后端。
- 国际化：文档与 UI 当前仅中文。

> 这一页会随项目演进持续更新；欢迎通过 PR 提交补充。
