# 快速开始

SAG Wiki 由 Go API、React Web 应用和一组本地基础设施组成。下面的流程会先准备 PostgreSQL、Redis、MinIO 与 Qdrant，再分别运行后端和前端。

## 环境要求

- Go 1.25.3+
- Node.js 20.19+ 或 22.12+
- pnpm 10+
- PostgreSQL 15+
- Redis 7+
- MinIO
- Qdrant

## 1. 准备基础设施

SAG Wiki 使用以下服务：

| 服务 | 默认地址 | 用途 |
| --- | --- | --- |
| PostgreSQL | `localhost:5432` | 业务数据 |
| Redis | `localhost:6379` | 异步任务队列 |
| MinIO | `localhost:9000` | 文档对象存储 |
| MinIO Console | `localhost:9090` | 存储管理界面 |
| Qdrant | `localhost:6333` | 向量与切片索引 |

这些服务可以使用本地安装、云服务或你自己的容器环境运行。文档仓库不再维护一份 Compose 配置；只要服务能通过上面的地址访问即可。

准备好 PostgreSQL 后，在 `sag-wiki` 主项目根目录执行数据库迁移：

```bash
createdb -h localhost -p 5432 -U postgres sag_wiki
psql -h localhost -p 5432 -U postgres -d sag_wiki -f server/migrations/system/001_schema.sql
psql -h localhost -p 5432 -U postgres -d sag_wiki -f server/migrations/wiki/001_schema.sql
psql -h localhost -p 5432 -U postgres -d sag_wiki -f server/migrations/ai/001_schema.sql
psql -h localhost -p 5432 -U postgres -d sag_wiki -f server/migrations/ai/002_schema.sql
```

如果你的 PostgreSQL 运行在其他环境，请使用对应客户端执行相同的 SQL 文件。

下面的 `server`、`web` 和 `server/migrations` 路径都来自 `sag-wiki` 主项目，不是当前文档仓库。

## 2. 配置并启动 Go API

```bash
cd server
cp .env.example .env
go mod download
go run main.go
```

API 默认运行在 `http://localhost:8080`。首次启动前，请按本地环境修改 `server/.env`，填入 PostgreSQL、Redis、MinIO 和 Qdrant 的地址与凭据，并确认数据库迁移已经执行。

## 3. 启动 React 应用

新开一个终端：

```bash
cd web
cp .env.example .env
pnpm install
pnpm dev
```

Web 应用默认运行在 `http://localhost:5200`。

## 4. 本地预览文档站

如需本地预览当前文档站：

```bash
cd sag-wiki-docs
pnpm install
pnpm dev
```
