## 提问方式

- 选择检索范围（文件夹、单个文档或不限）。
- 自由提问；流式回答与来源片段。
- 当前会话的检索上下文与历史消息展示。

## 流式事件

前端按 `StreamChunkEvent` 类型解析 SSE 流，事件类型包含：

- `stream_chunk`：模型增量输出。
- `tool_result_chunk`：工具调用增量结果。
- `message` / `tool_result`：聚合后的完整片段。
- `action`：前端动作提示。
- `error`：错误信息。

## 来源与可追溯性

- 每个回答附带来源切片与所属章节路径。
- 检索链路展示：问题向量化 → 权限过滤 → 片段召回 → 模型生成。

## 故障模式

- 模型不可用、检索无结果、文档未索引等情况下的提示与建议。
