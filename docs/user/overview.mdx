# 功能总览

> TODO：补充产品界面截图、功能清单表格与典型用户旅程。

## 面向团队成员

- 知识库：按目录树组织文档，文件夹与文档级别权限。
- 知识问答：基于已索引文档的 RAG 问答，支持指定文件夹或文档检索。
- 个人设置：账号信息、密码、应用偏好。

## 面向管理员

- 模型配置：聊天模型与 Embedding 模型凭据、参数与默认集合。
- 系统管理：用户、角色、部门与默认密码策略。
- 任务队列：解析、切片、向量化任务的状态、重试与清理。

## 典型场景

- 入库：上传文档 → 后台解析切片 → 写入向量集合 → 列表中显示已索引切片数。
- 检索：进入问答页 → 选择文件夹或文档 → 提问 → 流式回答 + 来源片段。
- 排查：任务队列查看失败任务 → 重试或丢弃 → 模型配置检查模型可用性。
