## 任务类型

- 文档解析（按文档类型走不同解析器）。
- 文本切片（语义分块器）。
- Embedding 写入（写入 Qdrant Collection）。

## 状态

- 待执行、执行中、已完成、失败、已重试。
- 状态字段在数据库与 Redis/Asynq 中的对应。

## 常见失败原因

- 文件下载失败（MinIO 凭据或网络）。
- 解析器未覆盖的文档类型。
- Embedding API 超时或配额耗尽。
- Qdrant Collection 不存在或维度不匹配。

- 在任务队列页触发单条重试。
- 对失败文档重新上传或重新入队的方式。
